# 学芸ポータル「お知らせ」転送システム
## ```🔥これは1年前の雪辱を晴らすため、最速で「全南大学サマースクール」に申し込む為に作られた執念とも言えるシステムである。```

東京学芸大学の学芸ポータル（gportal）に掲載される「お知らせ」「個人宛お知らせ」を定期的にチェックし、新着があればスマホへプッシュ通知するボットです。
GitHub Actions 上で自動実行されるため、サーバーや常時起動している PC は不要です

## 仕組み

```
GitHub Actions（10分おき）
   └─ portal_bot.py
        ├─ Playwright (Chromium) で学芸ポータルにログイン
        ├─ カテゴリごとにお知らせ一覧を取得
        ├─ 前回チェック時のタイトルと比較して新着を抽出
        ├─ 新着があれば ntfy.sh 経由でスマホへ通知
        └─ 最新タイトルを last_*.txt に保存し、リポジトリにコミット
```

- **チェック対象カテゴリ**
  - `個人宛お知らせ` → 状態は `last_personal.txt` に保存
  - `お知らせ` → 状態は `last_general.txt` に保存
- **新着判定**: 一覧を上から順に読み、前回保存したタイトルと一致するものが出てくるまでを「新着」として扱います。新着は古いものから順に通知されます。
- **状態の永続化**: GitHub Actions は毎回クリーンな環境で動くため、最後に見たタイトルを `last_*.txt` に書き出し、ワークフロー内で `git commit` / `git push` して次回に引き継ぎます。

## 通知の見え方

[ntfy](https://ntfy.sh/) を利用しています。スマホに ntfy アプリを入れ、自分のトピック名を購読しておくと、以下のような通知が届きます。

```
Gakugei Portal Update
【個人宛お知らせ】
〇〇について
```

優先度は `high`、タグは `bell` で送信されます。


## 実行スケジュール

`.github/workflows/check.yml` の cron で制御しています。

```yaml
- cron: '*/10 23,0-9 * * *'
```

GitHub Actions の cron は UTC 基準のため、上記は **日本時間 08:00〜18:50 の間、10 分おき** に相当します。時間帯を変えたい場合は UTC に読み替えて編集してください。

なお、GitHub Actions のスケジュール実行は負荷状況により数分〜数十分遅延することがあります。


実行すると `last_personal.txt` / `last_general.txt` が更新されます。

## ファイル構成

| パス                           | 役割                                             |
| ------------------------------ | ------------------------------------------------ |
| `portal_bot.py`                | ログイン・スクレイピング・通知を行う本体スクリプト |
| `.github/workflows/check.yml`  | 定期実行と状態ファイルのコミットを行うワークフロー |
| `requirements.txt`             | Python 依存パッケージ（`playwright`, `requests`） |
| `last_personal.txt`            | 「個人宛お知らせ」で最後に確認したタイトル         |
| `last_general.txt`             | 「お知らせ」で最後に確認したタイトル               |

## カスタマイズ

- **チェックするカテゴリを増やす / 減らす**: `portal_bot.py` の `CHECK_LIST` に、ポータルのプルダウンに表示されるカテゴリ名と保存先ファイル名のペアを追加・削除します。追加した場合は `check.yml` の `git add` の行にもファイル名を追記してください。
- **通知の文言や優先度**: `send_notification()` 内の `message` や `headers` を編集します。

## 注意事項

- 学芸ポータルの HTML 構造（ログインフォームの ID、一覧のクラス名 `.link-txt.break` など）が変わると動作しなくなります。通知が来なくなった場合は Actions のログを確認してください。
- 状態ファイルにはお知らせのタイトルがそのまま保存されます。リポジトリを公開する場合はその点に注意してください。
- ログイン情報は必ず GitHub Secrets に保存し、コードやコミットに含めないでください。
